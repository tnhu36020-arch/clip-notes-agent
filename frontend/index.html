How it works

  1. 1

    Check the link

    Only YouTube video and Shorts links are accepted.
  2. 2

    Retrieve captions

    The backend tries available subtitle tracks without downloading the video.
  3. 3

    Verify transcript text

    Caption-track metadata alone is not treated as a transcript.
  4. 4

    Summarize and mark uncertainty

    Only transcript content is summarized; timestamps are used when available.
  5. !

    If retrieval fails

    The site explains the failure and does not invent a summary.
